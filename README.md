# eurail-bus-details
Licensed native timetable detail assets for the independent Euro Rail bus layer; per-source rights apply.

This repository carries immutable detail partitions for the public
[Euro Rail atlas](https://gravelcycles.github.io/eurail-atlas/). Source snapshots,
service dates, native calls, clocks, boarding permissions and attribution remain
explicit in the records. The matching manifest, complete inventory and native
database offer live in the paired
[bus data repository](https://github.com/gravelcycles/eurail-bus-data).

Publisher data retains each source's own licence and credit. This repository
does not assert a blanket licence over third-party data. Acquired raw archives,
private staging databases, access credentials and withheld-trip evidence are
excluded. Published sources are partial; availability does not certify national
coverage, pass acceptance, exact road use or live operation.
